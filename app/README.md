# ЛР1 - Калькулятор
## Выполнил: Кирилл Е. (ИСУ 395713)

Данная работа представляет из себя простую реализацию калькулятора, использует стоковые темы из пэкеджа мобдев.

Работа соответствует следующему ТЗ:

### Простой калькулятор с максимально простой логикой.
### Что должно быть

- Считает в double
- Клавиатура (3х5, например)

### Чего не должно быть
- Потери значений при поворотах
- Блокировки поворота
- Падений
- Открытие стандартной клавиатуры
- Пакет или applicationId содержащий com.example
